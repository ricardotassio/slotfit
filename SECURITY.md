# Security and responsible use

SlotFit is a local synthetic experiment, not a clinical or scheduling product.
Do not submit real patient, provider, clinic, contact or health information to it.
The application has no authentication and should bind only to a loopback address.

If you discover a vulnerability, report it privately to the repository owner
before opening a public issue. Do not include real personal or health data in a
report. Until a public remote and private reporting channel exist, contact the
owner directly through an already-established private channel.

The current scope explicitly excludes public hosting, multi-user access, external
messages, booking and integration with a practice-management or health-record
system. Those changes require a new threat model and security review.
